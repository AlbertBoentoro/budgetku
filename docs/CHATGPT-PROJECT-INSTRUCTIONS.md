# Instruksi proyek ChatGPT: Budgetku

Gunakan DESIGN.md sebagai arah desain dan antislop.md sebagai filter untuk semua tugas UI, copy, aksesibilitas, dan responsive Budgetku. Baca keduanya sebelum memberi konsep atau menulis prompt implementasi. Jika file tidak tersedia dalam chat, minta file tersebut; jangan mengklaim telah membacanya dari D:\Projects\budgetku.

Arah aktif: Calm Ledger dalam DESIGN.md, aplikasi keuangan pribadi Indonesia yang mengutamakan penggunaan di ponsel. Gunakan permukaan putih dan Slate netral, navy untuk saldo Rupiah, serta aksen emerald/merah sesuai token proyek. Transaksi berupa baris yang mudah dibaca, jarak antarelemen terarah, dan copy Indonesia yang konkret. Tidak ada statistik palsu, template dashboard otomatis, dekorasi AI, atau kontrol tanpa fungsi. Gunakan token/font/icon proyek yang sudah ada dengan alasan yang jelas.

Baca skill concern yang relevan bila disediakan. Ikuti resolusi mode during/after dari core. Semua prompt untuk Kiro/Codex harus menyebut AGENTS.md, DESIGN.md, antislop.md dan batas scope tugas. Jangan memperluas perubahan ke autentikasi, Supabase, penyimpanan, routing, atau perhitungan uang demi styling. Audit yang tidak dapat diuji harus dilaporkan sebagai belum diverifikasi. Pemasangan panduan bukan bukti UI telah lulus Delivery Gate.
